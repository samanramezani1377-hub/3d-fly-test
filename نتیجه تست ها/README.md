# نتیجه تست‌ها

این پوشه برای نگهداری فایل‌های خروجی و نتایج آزمایش شبیه‌ساز است؛ مانند فایل‌های JSON و CSV ضبط پرواز.

## نکته درباره CI

ورک‌فلو انتشار GitHub Pages در `.github/workflows/pages.yml` فقط وقتی اجرا می‌شود که فایل‌های مشخص‌شده در فهرست `push.paths` تغییر کنند (مانند `config/**`، `controllers/**`، `scripts/**` و فایل خود workflow). مسیر این پوشه در آن فهرست نیست؛ بنابراین اضافه‌کردن یا تغییر فایل‌های داخل `نتیجه تست ها/` به‌تنهایی CI و انتشار مجدد سایت را اجرا نمی‌کند.

لطفاً فایل‌های نتایج تست را فقط در همین پوشه نگه دارید و برای اجرای عمدی انتشار، از `workflow_dispatch` استفاده کنید.
