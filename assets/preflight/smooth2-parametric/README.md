# مستند فنی خروجی smooth2-parametric

این پوشه فقط خروجی تولیدشدهٔ مدل مرجع است. هیچ فایل STEP یا STL در این پوشه منبع مستقل طراحی نیست.

## منبع دقیق این خروجی

- سازنده: `cad/parametric/drone_parametric.py`
- پارامترهای مرجع: `cad/parametric/model.params.json`
- دادهٔ مقاطع: `cad/parametric/body_sections.json`
- نسخه‌های وابستگی‌ها: `requirements.txt`

فایل `drone_parametric.params.json` snapshot بایت‌به‌بایت پارامترهای مرجع در زمان ساخت است. مقدارهای آن نباید جداگانه ویرایش شوند. گزارش و مانیفست هش SHA-256 ورودی‌های اصلی را نگه می‌دارند.

## فایل‌های اسمبلی

| فایل | معنی دقیق |
|---|---|
| `drone_parametric.step` | اسمبلی STEP نام‌گذاری‌شده با ۲۶ جزء مستقل |
| `drone_parametric.stl` | STL مونتاژشده؛ بایت‌به‌بایت برابر با فایل assembled |
| `drone_parametric_assembled.stl` | STL مونتاژشده با مختصات یکسان با اسمبلی STEP |
| `drone_parametric_exploded.stl` | چیدمان انفجاری نمایشی از همان اجزا؛ برای نمایش و بررسی قطعات |
| `drone_parametric.params.json` | snapshot تنظیمات همان اجرا |
| `assembly-manifest.json` | فهرست ۲۶ جزء، نقش‌ها، جهت خروجی و هش ورودی‌ها |
| `validation-report.json` | ابعاد، آزمون هندسه، تطابق STEP/STL و هش فایل‌ها |

## فایل‌های مستقل اجزا

برای هر یک از این اجزا، یک فایل STEP و یک فایل STL تولید می‌شود:

- `body_lower`: پوستهٔ پایینی و کف بسته؛
- `body_crown`: تاج بالایی جداشدنی؛
- `arm_1` تا `arm_4`: چهار مجموعهٔ بازو، محافظ و موتور؛
- `prop_1` تا `prop_4`: چهار پروانه؛
- `screw_1` تا `screw_8`: حجم‌های نمایشی پیچ؛
- `nut_1` تا `nut_8`: حجم‌های نمایشی مهره.

## اصول تطابق هندسی

۱. اسمبلی STEP و STL مونتاژشده مستقیماً از یک فهرست و همان جسم‌های CadQuery ساخته می‌شوند؛ جابه‌جایی مخصوص STL مونتاژشده مجاز نیست.

۲. STL پیش‌فرض باید از نظر بایت با STL مونتاژشده برابر باشد.

۳. STEP و STL هر جزء مستقل از یک شیء پارامتریک مشترک صادر می‌شوند و bounding box آن‌ها در گزارش مقایسه می‌شود.

۴. فایل انفجاری تنها خروجی دارای جابه‌جایی نمایشی است. این جابه‌جایی‌ها در STEP اسمبلی یا فایل‌های مستقل قطعات اعمال نمی‌شوند.

۵. جهت همهٔ خروجی‌های قطعات: محور عمودی `+Z`، جلوی دوربین `-Y` و زیر بدنه `-Z` است.

## کنترل‌های ثبت‌شده

- ۲۶ جسم در اسمبلی و یک solid برای هر فایل مستقل؛
- واردسازی مجدد ۲۷ فایل STEP؛
- watertight بودن ۲۶ فایل STL مستقل قطعات؛
- کنترل STL مونتاژشده از نظر غیرخالی بودن، تعداد مثلث، تطابق bounding box با STEP و یکسانی بایت‌به‌بایت نام پیش‌فرض با assembled؛
- کنترل STL انفجاری از نظر غیرخالی بودن و وجود وجه؛
- تطبیق bounding box جفت‌های ۲۶ جزء و اسمبلی STEP/STL؛
- یکسانی بایت‌به‌بایت STL پیش‌فرض و STL مونتاژشده؛
- تطبیق snapshot پارامترها با فایل مرجع؛
- هش SHA-256 سازنده، پارامترها، دادهٔ مقاطع و تمام فایل‌های STEP/STL.

نتیجهٔ معتبر، آخرین `validation-report.json` تولیدشده در اجرای موفق CI است.

## بازتولید

از ریشهٔ مخزن:

```bash
python -m pip install -r requirements.txt
python cad/parametric/drone_parametric.py
```

تنظیمات فقط در فایل مرجع `cad/parametric/model.params.json` تغییر می‌کنند. خروجی‌ها را دستی اصلاح نکنید.

## ابعاد و محدودیت‌ها

ابعاد نهایی، اندازهٔ قطعات و نتایج آزمون را از گزارش آخرین ساخت موفق بخوانید؛ این مستند عمداً اعداد تکراری را منبع دوم حقیقت نمی‌کند.

مدل بازسازی پارامتریک از اندازه‌گیری‌های مرجع است. سخت‌افزار پیچ و مهره به‌صورت ساده و بدون رزوه نمایش داده شده، سوراخ شفت پروانه باید با موتور واقعی هماهنگ شود و اتصال تاج به بدنه هنوز طراحی نهایی ندارد. آزمون‌های CAD جایگزین بررسی تلرانس چاپ، استحکام، بالانس یا تست پرواز نیستند.
